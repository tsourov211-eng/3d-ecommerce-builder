# Example: Sneaker Showroom

## Goal

Build a premium sneaker showroom using the original 2x5 dark-studio preset when the catalog has enough products and the viewport can support it.

## Visual direction

- Dark studio background with restrained orange or brand-colored accents.
- Individual platforms or pedestals.
- Three-quarter sneaker presentation with visible silhouette.
- Floating idle motion only if it does not distract.
- Emissive accent strip with a restrained glow.

## Interactions

- Select a shoe to focus the camera.
- Show product description, price and EU sizes.
- Change size before adding to the cart.
- Provide back-to-gallery and Escape behavior.
- Add swipe navigation on mobile.

## Data

Use actual product names, prices, currency, sizes, stock and GLB URLs. Sample product names and prices are illustrative only and must never be treated as a real catalog.

## Fallback

If a shoe model is missing, use a simple procedural shoe-like placeholder or product image and preserve the HTML details and variant controls.

## Acceptance

Check desktop grid framing, close-up camera focus, size selection, cart line behavior, mobile layout and missing-model fallback.
